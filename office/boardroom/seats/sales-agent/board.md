# Sales Agent — Personal Board

Sales Agent's own board: working notes, reminders, flags for Sloane.
Notes for other seats go on the shared board (`office/boardroom/board.md`).

Use the CLI against this board:

```bash
BOARDROOM_BOARD=office/boardroom/seats/sales-agent/board.md \
  office/scripts/boardroom.sh post --from sales-agent --to sales-agent \
  --subject "..." --body "..."
```
