# Document Artisan — Personal Board

Use the CLI against this board:

```bash
BOARDROOM_BOARD=office/boardroom/seats/document-artisan/board.md \
  office/scripts/boardroom.sh post --from document-artisan --to document-artisan \
  --subject "..." --body "..."
```
