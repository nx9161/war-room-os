# Memory Keeper — Personal Board

Memory Keeper's own board: working notes, reminders, flags for Sloane.
Notes for other seats go on the shared board (`office/boardroom/board.md`).

Use the CLI against this board:

```bash
BOARDROOM_BOARD=office/boardroom/seats/memory-keeper/board.md \
  office/scripts/boardroom.sh post --from memory-keeper --to memory-keeper \
  --subject "..." --body "..."
```
