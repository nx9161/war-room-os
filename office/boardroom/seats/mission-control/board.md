# Mission Control — Personal Board

Mission Control's own board: working notes, reminders, flags for Sloane.
Notes for other seats go on the shared board (`office/boardroom/board.md`).

Use the CLI against this board:

```bash
BOARDROOM_BOARD=office/boardroom/seats/mission-control/board.md \
  office/scripts/boardroom.sh post --from mission-control --to mission-control \
  --subject "..." --body "..."
```
