# Casting Director — Personal Board

Casting Director's own board: working notes, reminders, flags for Sloane.

Use the CLI against this board:

```bash
BOARDROOM_BOARD=office/boardroom/seats/casting-director/board.md \
  office/scripts/boardroom.sh post --from casting-director --to casting-director \
  --subject "..." --body "..."
```
