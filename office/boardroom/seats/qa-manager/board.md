# QA Manager — Personal Board

QA Manager's own board: working notes, reminders, flags for Sloane.
Notes for other seats go on the shared board (`office/boardroom/board.md`).

Use the CLI against this board:

```bash
BOARDROOM_BOARD=office/boardroom/seats/qa-manager/board.md \
  office/scripts/boardroom.sh post --from qa-manager --to qa-manager \
  --subject "..." --body "..."
```
