# Product Visualizer — Personal Board

Product Visualizer's own board: working notes, reminders, flags for Sloane.
Notes for other seats go on the shared board (`office/boardroom/board.md`).

Use the CLI against this board:

```bash
BOARDROOM_BOARD=office/boardroom/seats/product-visualizer/board.md \
  office/scripts/boardroom.sh post --from product-visualizer --to product-visualizer \
  --subject "..." --body "..."
```
