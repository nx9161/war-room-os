## Entries

### 2026-11-14 — Director self-improvement loop, passes 17–66

- **What worked:** Recording every pass in the virtual-office wing and
  the INDEX ADRs — the loop's history is complete and auditable there.
- **What failed:** This file stayed at "(none yet)" for the loop's
  entire run. The seat-coverage counter reads only this file (plus the
  brain log), so it counted the Director cold in every report —
  including the corrected 28 used / 17 cold of pass 62 — while she ran
  every mission the counter was measuring. Wing entries are history;
  they are not the evidence source the metric reads.
- **Change for next time:** Evidence of a seat's work must land in the
  file the measurement actually reads, or the seat reads as never
  seated no matter how much work happened elsewhere. When a metric
  marks an obviously active seat cold, check whether its evidence
  lives in the wrong file before trusting either number — and the
  Director's own file is not exempt from the log-after-every-mission
  rule she enforces on everyone else.
